## Physical playtest intake (Derrick, 0.0.63)

### P1 — Equipment config authoring surface is wrong

Observed screenshot facts:
- Equipment configuration is a raw YAML textarea instead of grouped field controls.
- Drawer/fieldset width is too narrow.
- Apply/Reset/Export labels wrap and clip at a very large font size.
- Hand equipment is not visible during Test.

Required behavior:
- Remove YAML text editing from the panel.
- Present grouped, labeled, directly editable values using the established environment-variable editing pattern.
- Apply every accepted field change live to the next rendered equipment frame so Derrick can visually tune it.
- Keep deterministic YAML export for baking finalized defaults, but do not expose YAML as the editing model.
- Make the authoring drawer/section wide enough for its content and use compact non-clipping buttons.
- Add a Test-only hand-equipment visibility toggle, default `off`; switching it on must immediately show the equipment in Test when input/preview evidence exists.
- Diagnose and eliminate the Info-box error: `Cannot read properties of undefined (reading 'rotationZDeg')`.

### P2 — Off-grid wrist motion still restarts calibration

Observed: moving wrists outside the calibrated range still causes gameplay to pause and/or calibration to restart in the physical camera path.

Required invariant:
- A calibrated session with the same camera source must not pause, invalidate calibration, or restart calibration merely because confident wrists leave the calibrated grid.
- Finite off-grid wrists may remain staged for presentation, with null cell/subcell and no scoring.
- Deliberate in-play T-pose recalibration, true source identity changes, explicit reset, and uncalibrated startup remain fail-closed.

### P3 — Periodic Boxing frame halts

Observed: in Boxing, every few beats the game halts for several frames. Reproduction song: Beat Saber **Wario Ware**, difficulty **Hard**.

Required behavior:
- No periodic multi-frame main-thread/display halt tied to beat cadence, target family, feedback, allocations, logging, collision settlement, or renderer staging.
- Diagnose with target-hardware profile evidence using the exact chart where available; preserve score/render semantics.
