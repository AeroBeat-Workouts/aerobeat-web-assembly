## W0 findings (all read-only; file:line evidence in subagent reports)

### 2dh7 — the "undodgeable duck" is a contract-legal but INFEASIBLE squat
- Boxing obstacle taxonomy (contracts + `converter.js:291`): one hazard class → three derived actions: flow `obstacle` (any 4×3 rect, nose-avoid), `weave_left`/`weave_right` (single lane-col, full height, width=1 height=3), **`squat`** (balanced mask; canonical = full-width TOP ROW only). No separate "duck" type; "duck" only appears in the `no_squats` accessibility modifier.
- **Renderer by design**: a `family==="squat"` target in boxing duplicates its wall once per lane, each full lane height (Y 2.47…−0.47) — `gameplay-scene-model.js:256-263`. Two full-row colliders = ONE squat beat.
- **Root cause (high confidence)**: BeatSaver source obstacle full-width (v3 `{x:0,y:0,w:4,h:3}`) or ANY v2 legacy obstacle (v2 forces full-height, `beatmap.js:208-210`) → converter emits `squat` with `gridMask [0..11]`, `noseSafeCells []` — **literally undodgeable**. Verified read-only by running the real converter (`node -e`): v3 full-width → squat/empty safe cells; v2 width-4 → squat, mask `[1,2,5,6,9,10]`.
- **Defect class**: content-feasibility gap — every validator checks mask/type/safe-cell *consistency*, never *feasibility*. Punches get `spatial_target_blocked`/`unreachable_after_optimizer` drops (`converter.js:199-207`); squat/weave emission (`converter.js:215-221`) has no such gate.
- Canonical squat fixtures: `validate-content-runtime.js:852`, `validate-task11-actual-services.js:58` — gameplay `{x:0,y:0,w:4,h:1}`, mask `[0,1,2,3]`, `noseSafeCells [4..11]`; player ducks (nose stays in a bottom/mid cell), checkpoint is a nose-in-cell judgement.

## Design detail (superseded where GATE 1 locked decisions above differ)

### Equipment = detection volumes (the core architectural change)
- Flow: **saber capsule** ∩ note cell box at z=0 within judge window = HIT. Replaces wrist-in-cell entirely (single detector; `judgedIds` double-hit guard stays).
- Boxing: **glove volume** is the detection primitive replacing the wrist-sample box — glove volume ∩ punch target box within timing window = HIT; overlap-only semantics preserved (F3: no hand-qualification reintroduced). Guard poses judge the same way via the glove volume.
- Glove volume definition (v1): hand-sized box ~0.34 × 0.28 × 0.34 centered at the wrist sample, local frame fixed (x = thumb side, mirrored per hand; y = up; z = grid-facing); center offset +0.05 grid-facing so the volume covers the fist. Orientation stays fixed facing in v1 (motion/fist-normal orientation = tuning follow-up, also the VR-port seam).
- **Space-consistency invariant**: detection volumes are defined in the JUDGE space (same normalized 4×3 wrist space as the existing punch boxes; columns 0..3, `sx = 4·x_norm − 0.5`), while the rendered equipment lives in presentation space (`columnX = [-1.5,-0.5,0.5,1.5]` = judge X − 1.5). The visible equipment size/offset MUST be derived from the same shared constant as the detection volume — "what you see is what hits" (the F2-class coordinate-space trap, now a named invariant).
- Why (Derrick): a VR port drives the equipment volumes directly from controller poses — detection lives on the equipment, never re-touched.
- **All wrist markers HIDDEN** in both modes (equipment is the visible + detection surface); **nose marker HIDDEN** (obstacle nose detection unchanged). Cursor-record path still feeds equipment staging; freeze-dim 0.45 applies to equipment records automatically.

### Saber (chgy)
- Directed beam, length ~0.75 WU, radius ~0.18 WU capsule, along smoothed last-motion direction (fallback facing). Trail slash (B) only if A proves insufficient in playtest.
- Cut = existing slice aftermath (signed-off look); optional 60–100 ms impact flash at intersection (tuning).
- Rendering: additive-glow capsule (emissive per-hand song tint, `mat/tint_base`-style fill role) + brighter core line; slight length pulse on hit. Asset `equipment/flow-saber-v1` + `cueMaterialRoles` entry; staged in the cursor pass at athlete plane Z=0.45.

### Gloves (hk5q)

- Oracle: glove at each wrist, per-hand color, dims on freeze, and the DETECTION oracle (glove-volume hit/miss vs target box, both hands).
