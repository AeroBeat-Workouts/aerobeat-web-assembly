**Design contract:** Game Setup stores `flowCorpseFade` and `boxingCorpseFade` as independent `{enabled:boolean,delayMs:number,durationMs:number}` records. Initial saved values are `{enabled:false,delayMs:150,durationMs:500}` for each mode (disabled until Derrick opts in). Assembly attaches them each render to optional `frame.aftermathFadeByMode={flow:flowCorpseFade,boxing:boxingCorpseFade}`. Renderer owns `aftermathPose`/`aftermathObjects` and existing fade-to-alpha material path. Optional frame field absent means exact original behavior; a malformed present field rejects. Flow family uses Flow settings, all Boxing aftermath families use Boxing settings. With timer OFF, current offscreen and FIFO-eviction behavior stays byte-equivalent in effect. With timer ON, fade is based on elapsed song time since each hit: full opacity through delay, linear alpha to zero across duration, and no scene object afterward; preserve bounded eviction/lifecycle cleanup. Avoid dither until an actual transparency artifact establishes a need. Finite nonnegative values have no arbitrary upper cap; reject invalid storage/UI/API values and avoid overflow/zero division. The two per-mode settings are independent and saved/migrated with existing v3 Game Setup records; later explicit values survive reconnect and reload.
