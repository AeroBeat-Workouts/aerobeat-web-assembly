## Diagnosis before implementation

- **Observed:** actual native scored play has first-hit and sustained severe renderer-call tails; corpse-off scores more individual hits with all intended pieces withheld and severe tails absent. Neither mode restores the earlier >100-FPS miss-swing cadence. The exact on-only renderer substage is unknown.
- **Expected:** actual exported Test JSON should show, per valid window and hit-linked display frames, counts of new/reused corpse pool entities, slice material cache misses/hits/high-water, bounded wall times for those operations, clipped appearance application, scene update and renderer manual tick. The off-mode cut still constructs aftermath in gameplay but skips these on-only operations. To distinguish *creating* a variant from merely drawing existing halves, split eligible native display frames into bounded **cache-miss** and **aftermath-without-new-variant** cohorts; compare full-frame/scene-update/manual-tick histograms across those cohorts and the existing off control, without exporting per-frame records. All fields are scalar/histogram aggregates, never cut coordinates/material keys or per-note records.
- **Path:** scored `runDisplayFrame` → scene projection → wrapper on `updateSceneObjects` → historical facade `acquireAftermathAssetEntity` / `applyAftermathAppearance` / `sliceVariantMaterial` / `installSliceClipBlocks` → `manualTick`. Existing wrappers already measure eligible display cadence, renderer facade total, score deltas and 1.2-second post-hit unions. The new wrappers must attach to that same frame/window generation without timing ineligible setup/menu frames as eligible phone samples.
- **Leading hypothesis and alternatives:** unique cut parameters trigger cache misses/material setup and perhaps browser shader compilation. Alternatives are pooled entity growth, every-frame material appearance updates, actual draw/GPU sync during `manualTick`, or other hit/model/full-app cost. The off-only scene filter also removes all corpse draw work; the native/off aggregate alone cannot choose among these. The earlier synthetic no-hit/shadow-off page failed to recreate sustained real-song jank; broad renderer timing narrowed but did not locate it.
- **Verification before fix:** in a project-owned real imported-chart browser fixture, native scored hit/group frames must cause nonzero variant probes, off scored hit frames must still observe/withhold aftermath but cause zero new corpse scene operations, and a same-script removal of only new instrumentation must fail the new report assertion then pass when restored. Existing corpse pixels, Great/sky/target/track/saber, playing-touch/paused downloads, bound/privacy and error assertions stay active. Synthetic fixture timings are not physical-phone FPS or GPU timing.
