6. **Iteration model:** `xshm` sweep harness contact sheets → Derrick sign-off per asset (human-in-the-loop, like the 0.0.60 corpse sweep) → signed-off look locked as reference → assert-after real-pixel oracle in the gate chain. No production build until both assets are signed off.
