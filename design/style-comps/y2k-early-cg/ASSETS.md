# Assets — y2k-early-cg

## Fonts (both SIL Open Font License 1.1)

| File | Font | Source | Licence |
|---|---|---|---|
| `fonts/Michroma-Regular.ttf` | Michroma, by Vernon Adams (The Michroma Project Authors) | https://github.com/google/fonts/tree/main/ofl/michroma | OFL 1.1 |
| `fonts/Jost-Variable.ttf` | Jost (variable weight), by indestructible type* | https://github.com/google/fonts/tree/main/ofl/jost | OFL 1.1 |

Both are loaded with `FontFace` before any text canvas is drawn.

## Everything else is procedural

Built in code, with no downloaded files: the chrome sphere map, the airbrushed sky, cirrus streaks, fractal ridge, horizon fog band, checker floor, ringed planet, fake-glass slab, gem mesh, gem halos, sparkle and wrist-marker textures, and every lens-flare element (glow, rays, anamorphic streak, ghost rings and hexes).

## Content

Playlist covers come from `_shared/content.mjs` through `coverUrl()`, as the brief requires. No game art, logos or reference images found during research were downloaded or used.
